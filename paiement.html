Payer un marchand en un scan

Chez un commerçant, une école ou une université DIAUNY, scannez son QR code et payez en quelques secondes. Plus besoin de monnaie.

Frais pour vous : 0 F
Étape par étape

Comment payer

  1. Appuyez sur « Paiements »

    Ouvrez DIAUNY. Dans les Actions rapides, appuyez sur Paiements. L'appareil photo s'ouvre.

  2. Scannez le QR du marchand

    Placez le QR code DIAUNY affiché à la caisse dans le cadre. Le nom du marchand apparaît.

  3. Confirmez avec votre empreinte

    Posez votre doigt pour confirmer que c'est bien vous qui payez.

  4. Saisissez le montant

    Entrez la somme demandée par le marchand. L'écran indique « Aucun frais — paiement marchand ». Appuyez sur Payer.

  5. Paiement réussi

    Le message de confirmation s'affiche avec le nom du marchand. Le marchand reçoit l'argent immédiatement.
